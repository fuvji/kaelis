2. INSTALLATION METHODS
==============================================================================

  2.1 Windows portable (recommended for a current build)
    Download Kaelis-Portable.zip, extract it anywhere you can write, and
    run Kaelis.exe. There is no installer and no bundled runtime download
    for the launcher itself. To keep instances and settings beside the
    executable, set KAELIS_DATA_DIR to that folder before launching.
    Data: %APPDATA%\kaelis\Kaelis\data (default)
          %APPDATA%\kaelis\Kaelis\data\instances

  2.2 Windows installer
    Download Kaelis-Setup.exe and run it. It installs per user under
    %LOCALAPPDATA%\Programs\Kaelis, adds Start menu and desktop shortcuts,
    registers an uninstaller, and needs no administrator rights.
    Uninstall: Settings > Apps > Kaelis, or Uninstall.exe in that folder.
    The installer carries the same Kaelis.exe build as the download page.

  2.3 macOS
    Prebuilt: Kaelis-macos-universal.zip from the latest release; drag
    Kaelis.app to /Applications.
    From source: ./packaging/macos/bundle.sh [--universal]
    Output: dist/Kaelis.app
    Data: ~/Library/Application Support/gg.kaelis.Kaelis/instances

  2.4 Linux
    Prebuilt: Kaelis-linux-x64.tar.gz from the latest release; extract and
    run ./kaelis, or install the binary and desktop entry.
    From source: ./packaging/linux/install.sh
    Installs: ~/.local/bin/kaelis
              ~/.local/share/applications/kaelis.desktop
              ~/.local/share/icons/hicolor/scalable/apps/kaelis.svg
    Data: ~/.local/share/kaelis/instances
    Build packages: libgtk-3-dev libayatana-appindicator3-dev
                    libxkbcommon-dev libwayland-dev libx11-dev

  2.5 Build from source
    Requirements: Rust 1.85+ and a C/C++ linker for the target.
    Windows: stable-x86_64-pc-windows-msvc + Visual Studio C++ workload
    macOS:   stable-aarch64-apple-darwin or stable-x86_64-apple-darwin
    Linux:   stable-x86_64-unknown-linux-gnu
    Commands:
      git clone https://github.com/epufk/kaelis.git
      cd kaelis
      cargo build --release -p kaelis-launcher
      target/release/kaelis --version

  2.6 Where data lives
    Windows  %APPDATA%\kaelis\Kaelis\data
    macOS    ~/Library/Application Support/gg.kaelis.Kaelis
    Linux    ~/.local/share/kaelis
    Override any platform with KAELIS_DATA_DIR=<folder>.
    Instances live under <data>/instances/<instance-id>/ with mods,
    resourcepacks, shaderpacks, saves, config, logs, runtime, and versions.
    Settings: <data>/settings.json. Microsoft refresh tokens: OS keychain
    under service 'kaelis'. Access tokens never touch disk.

  2.7 Command line
    kaelis                         Open the desktop launcher
    kaelis --version [--json]      Build identity and public URLs
    kaelis --status [--json]       Data root, instances, accounts, Java
    kaelis --list-instances [--json]
    kaelis --list-versions [--show-alpha] [--show-beta] [--hide-snapshots]
    kaelis --accounts [--json]
    kaelis --use-account <name> [--json]
    kaelis --offline <name> [--json]
    kaelis --play <instance> [--offline <name>]
    kaelis --install-mod <instance> <modrinth:project|curseforge:id|slug>
    kaelis --repair <instance>
    kaelis --check-updates <instance> [--json]
    kaelis --update-mods <instance> [--json]
    kaelis --import-modpack <instance> <pack.mrpack|pack.zip>
    kaelis --export-instance <instance> <out.kaelis.zip>
    kaelis --import-instance <archive.kaelis.zip>
    kaelis --duplicate <instance> [--with-worlds] [--json]

3. RUNTIME SERVICE URLS
==============================================================================
  These are the endpoints the launcher contacts. Dynamic URLs are shown as
  patterns; values in <angle-brackets> come from Mojang or provider metadata.

  3.1 Mojang / Minecraft Services
  Version manifest (GET)
    https://piston-meta.mojang.com/mc/game/version_manifest_v2.json
    Every install begins here.
  Version metadata (GET, per version)
    https://piston-meta.mojang.com/v1/packages/<sha1>/<version>.json
    URL supplied by each version_manifest entry.
  Mojang libraries (GET)
    https://libraries.minecraft.net/<group>/<artifact>/<version>/<file>
    Fallback base when version metadata omits a library URL.
  Asset objects (GET)
    https://resources.download.minecraft.net/<first-2-hex>/<hash>
    SHA-1-addressed game assets.
  Java runtime catalogue (GET)
    https://piston-meta.mojang.com/v1/products/java-runtime/2ec0cc96c44e5a76b9c8b7c39df7210883d12871/all.json
    Selects the version-matched Mojang JDK.
  Java runtime files (GET)
    https://piston-meta.mojang.com/<runtime-manifest-path>
    Manifest URL is supplied by the runtime catalogue.
  Premium name lookup (GET)
    https://api.mojang.com/users/profiles/minecraft
    Append /<username>; resolves an offline name's premium UUID and skin.
  Minecraft EULA
    https://www.minecraft.net/en-us/eula

  3.2 Microsoft / Xbox Live authentication
  Device code (POST)
    https://login.microsoftonline.com/consumers/oauth2/v2.0/devicecode
    Scope: XboxLive.signin offline_access openid profile.
  Browser authorize (GET)
    https://login.microsoftonline.com/consumers/oauth2/v2.0/authorize
    Authorization-code + PKCE flow.
  Token exchange (POST)
    https://login.microsoftonline.com/consumers/oauth2/v2.0/token
    Device-code polling and refresh.
  Xbox Live user auth (POST)
    https://user.auth.xboxlive.com/user/authenticate
  XSTS authorize (POST)
    https://xsts.auth.xboxlive.com/xsts/authorize
  Minecraft login (POST)
    https://api.minecraftservices.com/authentication/login_with_xbox
  Minecraft profile (GET)
    https://api.minecraftservices.com/minecraft/profile
    Confirms the profile after sign-in.
  Local OAuth callback
    http://localhost:<ephemeral-port>/
    Loopback only; the port is bound before the browser opens.
  Xbox relying-party identifier
    http://auth.xboxlive.com
    Protocol value, not a network request.
  Entra device-code documentation
    https://learn.microsoft.com/entra/identity-platform/v2-oauth2-device-code
  Entra app registrations
    https://portal.azure.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade
    Where the optional public client ID is created.

7. VERIFY A DOWNLOAD
==============================================================================
  Windows:
    certutil -hashfile Kaelis.exe SHA256
  macOS / Linux:
    shasum -a 256 -c SHA256SUMS.txt
  Compare against https://epufk.github.io/kaelis/downloads/SHA256SUMS.txt.
  A mismatched file is not a Kaelis release.
