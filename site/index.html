What changed

The game gets the machine.

Every lever is applied at spawn, held for the life of the process, and released on exit.

01

Realtime priority, with a floor

A launched JVM is promoted to REALTIME_PRIORITY_CLASS right after spawn. A normal desktop refuses that privilege, so the same call settles on HIGH_PRIORITY_CLASS — never on normal priority.

02

A 0.5 ms scheduler tick

The launcher holds NtSetTimerResolution(5000) for exactly as long as the game runs, with timeBeginPeriod(1) as the fallback, and drops it on a crash, a Stop, or a normal exit. Pre-2004 Windows applies that tick machine-wide; newer builds scope it to the calling process.

03

No EcoQoS parking

The game process is opted out of Windows' execution-speed throttling, so an alt-tabbed or full-screen session keeps the performance cores instead of drifting onto efficiency cores.

04

JVM flags that fit a client

Parallel reference processing and no shared hsperfdata mapping. Region sizes, pause targets, and thread counts stay on HotSpot's ergonomics — unmeasured GC knobs are not worth the risk.

05

Natives unpack once

The first launch of a version extracts its LWJGL, JNA and Netty natives into a cache keyed by the version document and every native jar's size and mtime. Later launches reuse that directory instead of unzipping it again, and an upgraded jar always produces a new key.

The game-process work shipped in 0.5.0; the native cache is new in 0.6.0. Downloads below point at the latest published tag.

Everything in one place

Small by design.

No wizards, no dashboards, no accounts to create, no service running behind the window.

01

Auto Erase Junk

Logs, caches, crash dumps and stale launcher state go at every start. Saves, mods, configs and unknown folders stay. A symlinked root is refused rather than followed.

02

One copy of the game

Verified files are hard-linked once, so a second instance of the same version costs megabytes instead of six hundred. Deleting one never damages another.

03

Auto-repair

A missing JVM, jar, library, asset or loader is refilled before the game starts — on a fresh machine and after a crash alike.

04

Keyless catalogue

All of Modrinth and CurseForge in one search. No API key, no account, no scraper. Downloads are hash-checked and dependencies resolved.

05

Managed Java

The runtime the version asks for is provisioned on first play. JDKs already on the machine are found and used instead of downloading another.

06

Portable instances

.kaelis.zip round trip, plus Prism/MultiMC, CurseForge and .mrpack imports. Worlds are opt-in on duplicate.

07

Runs in parallel

Per-instance guards let different instances run at once, and a running game still shows as running after the launcher reopens.

08

Hibernates while you play

Play hides the window and empties its working set. One tray click brings it back above the game; the taskbar entry stays.

09

Private by default

No telemetry, no analytics, no daemon. Tokens live in the OS keychain, and each instance launches with telemetryOptIn:false written for the game.

10

Updates in one click

Every release is SHA-256 verified against the published checksum, backed up before the swap, and rolled back if the new build cannot start.

Straight answers

Before you install.

Is Kaelis free?

Yes. Free to download and use. Kaelis is proprietary software, so redistribution and modification are not permitted. No paid tier, no account.

Does it need a Microsoft account?

No. Offline profiles work immediately and show the premium skin that owns the name. Microsoft sign-in is optional: one click, a short code on the Microsoft page, and the refresh token stays in the OS keychain.

Does it collect anything?

No telemetry, no analytics, no background services. Kaelis contacts Mojang, Modrinth and CurseForge only for the files you ask for. It also writes telemetryOptIn:false into each instance's options.txt before launch.

Do I need a CurseForge API key?

No. CurseForge is read through the public mirror of its v1 API — same catalogue, same metadata, no key — and files come from the official CDN with hash and dependency checks. An approved key in CF_API_KEY switches to the official endpoint.

Is the Windows build signed?

No commercial certificate, so SmartScreen may ask once. Verify the SHA-256 checksum and only run a copy from this page or the GitHub release.

Can I run it without installing?

Yes. Use the portable ZIP. Set KAELIS_DATA_DIR to keep instances and settings beside the executable.

Will realtime priority hurt the rest of the desktop?

The game is promoted to realtime only when the host grants the privilege; an ordinary desktop lands on high. The class belongs to the game process, not its threads' individual priorities, and Kaelis keeps no hook, timer or watchdog on it.
