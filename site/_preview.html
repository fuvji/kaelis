Engineered small

Fast because it is native.

Kaelis is a Rust workspace with a lightweight egui interface. There is no bundled browser, no JavaScript runtime, and no background analytics pipeline.

Native event loop

The UI paints only when something changes. When the window loses focus it can idle instead of burning frames in the background.

Bounded work

Search is debounced, thumbnails decode under strict pixel and byte limits, and dependency resolution has a hard request budget.

Managed runtime

Kaelis provisions a matching Java runtime for the instance, so a fresh machine does not need a hand-built Java setup.

Parallel transfers

Assets and libraries download through a bounded concurrent queue with retries and checksum verification, not a serial crawl.

Compact by default

Release builds use fat LTO, one codegen unit, symbol stripping, and abort-on-panic. The result is a small single executable.

Readable state

Instances are plain JSON with atomic saves. No database daemon, opaque cache, or migration service sits between you and your setup.

Quiet automation

The maintenance you should not have to remember.

Automation is explicit, inspectable, and off the critical path. Kaelis never silently changes an instance without a clear rule you can disable.

Repair before launch

  • Missing mod idsResolved on Modrinth
  • Dependency graphInstalled in one pass
  • Fabric API modulesProvisioned when absent
  • Failed resolutionReported, never hidden

Duplicate control

  • Same top-level mod idNewest jar wins
  • Older duplicateDisabled, not deleted
  • Safety proofEvery other id still satisfied
  • Manual overrideAlways available
Local-first

Your setup stays yours.

Instance state is local. Logs live in a bounded in-memory ring and disappear when Kaelis closes. Refresh tokens go to the operating-system credential store, never to a file in your instance folder.

No telemetry No analytics No cloud sync No background uploader

Straight answers

Before you install.

Is Kaelis free?

Yes. The launcher is MIT licensed and the full source is on GitHub. There is no subscription, telemetry, or upsell inside the app. An account is only needed if you want to join online-mode servers.

Can I sign in with my Microsoft account?

Yes. Kaelis uses Microsoft's public-client device-code flow and keeps the refresh token in Windows Credential Manager. Because each launcher must own its Microsoft Entra application, add a public-client ID in Settings → Integrations first; the Account panel links to the exact app-registration steps. Offline profiles work immediately without any setup.

Why do CurseForge results ask for a key?

CurseForge requires every client to send its own API key. A free key from console.curseforge.com enables those results. Modrinth works without a key, and local file or direct-URL installs work without either provider.

Does Kaelis replace the official Minecraft launcher?

No. Kaelis is an independent launcher and is not affiliated with Mojang Studios or Microsoft. It provisions game files from Mojang's official metadata and uses your own Microsoft account when you choose to sign in.

Is the installer signed?

The build carries product metadata but is not code-signed with a commercial certificate, so Windows SmartScreen may show a warning. Verify the SHA-256 checksum above and only run a copy downloaded from this page or the official GitHub release. The repository includes the exact NSIS installer script for auditing.
